# 🧪 산-염기 탐구 실험실 (Science Lab App)

**"교실 안의 작은 실험실"** 이 프로젝트는 초등 과학 교육과정의 **'산성과 염기성'** 단원을 학습하기 위해 개발된 인터랙티브 웹 애플리케이션입니다.  
Streamlit을 기반으로 제작되었으며, 물리적인 실험 도구 없이도 다양한 용액과 지시약의 반응을 시각적으로 체험할 수 있습니다.

---

## 🎯 프로젝트 목적
1.  **안전한 가상 실험:** 위험한 시약 없이 웹상에서 안전하게 산-염기 반응을 관찰합니다.
2.  **데이터 기반 학습:** 실험 결과를 자동으로 기록하고, 학급 전체의 오답률을 분석하여 학습 성취도를 파악합니다.
3.  **AI 활용 확장성:** **Google Gemini API**를 연동하여, 기본 용액 외에 학생들이 궁금해하는 다양한 용액의 성질을 AI가 예측하고 추가할 수 있습니다.

---

## ✨ 주요 기능

### 👨‍🎓 학생용 (Student Mode)
* **가상 실험 수행:** 용액(레몬즙, 비눗물 등)과 지시약(리트머스 종이, 페놀프탈레인)을 선택하여 색깔 변화를 관찰합니다.
* **탐구 일지 작성:** 실험 결과가 자동으로 '나의 탐구 일지'에 기록됩니다.
* **과제 제출:** 학년/반/번호/이름을 입력하여 실험 기록을 선생님께 파일 형태로 전송합니다.
* **새로운 용액 요청:** 실험해보고 싶은 용액이 목록에 없다면 선생님께 추가 요청을 보낼 수 있습니다.

### 👩‍🏫 교사/관리자용 (Teacher Mode)
* **보안 로그인:** 설정된 관리자 비밀번호로 인증해야만 접근 가능합니다.
* **요청 용액 관리 (AI):** 학생들이 요청한 용액의 성질(산성/염기성)을 **AI(Gemini)**가 1차로 예측해주며, 선생님이 이를 검토 후 실험 목록에 추가할 수 있습니다.
* **제출물 관리:** 학생들이 제출한 탐구 일지를 확인하고 관리합니다.
* **학습 데이터 분석:** 학생들의 실험 데이터를 통합하여 **'용액별 오답률'**과 **'지시약별 오답률'**을 시각적인 차트(Chart)로 제공합니다.

---

## 🛠 사용 기술 (Tech Stack)
* **Language:** Python 3.x
* **Web Framework:** Streamlit
* **Data Analysis:** Pandas
* **AI Model:** Google Gemini (gemini-2.0-flash)
* **Data Storage:** JSON (File-based storage)
